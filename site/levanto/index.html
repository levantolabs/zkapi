How it works

    
    
      
  1. Deposit. Your ETH goes into an open-source vault contract, as a private note only your browser can spend.
    2. 
      
  2. Prove, don't reveal. Your browser proves it holds enough balance without saying which deposit is yours, and gets a short-lived key.
    3. 
      
  3. Call Sage. Use the key like any API key. When it expires, only what you used comes off your balance.
    4. 
    

    
Experimental: the protocol is new and unaudited. Keep deposits small. Your note lives in this browser; clearing site data before withdrawing loses it. Built on zkAPI.
